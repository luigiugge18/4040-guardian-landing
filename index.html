Frequently Asked Questions

Do I need a Webflow Enterprise plan? ▾

No. Anyone can log 404s and export CSVs. Only the direct redirect API requires Enterprise access.

Which data does the app collect? ▾

We store 404 paths, basic event metadata (timestamp, referrer, user agent), and encrypted OAuth tokens. No visitor personal info.

How often should I export CSVs? ▾

We recommend weekly exports or whenever new campaigns go live.

Can multiple teammates collaborate? ▾

Yes. Premium workspaces (coming soon) will support role‑based access and shared dashboards.

What if a suggestion is wrong? ▾

You always control the mapping. If no suggestion fits, create your own redirect manually.

How do I uninstall? ▾

Disconnect via the dashboard’s logout, clear data with /disconnect, and remove the app in Webflow settings.
